使用 PikeSun 构建现代设计系统

一套优雅的配色、双语字体与组件模式，帮助你在中文 Web 项目中高效落地一致的设计语言。

力太阳团队 · 2026-07-14 · 12 分钟阅读

一、设计理念

PikeSun（力太阳）的核心是一套 克制而温暖 的设计语言。以奶油白 #fefcf6 为基底，搭配深邃的墨色 #1A1A2E 与克制的蓝色强调 #0071E3，在专业感与亲和力之间找到平衡。

这套系统专为中英文混排优化——标题使用 Noto Serif SC 与 Fraunces， 正文使用 Noto Sans SC，并保留了手写体 Caveat 用于注释与点缀。

色彩体系

六个主色构建完整情绪光谱。主色蓝提供信任与稳定；强调色橙注入活力与行动； 弹出红用于关键警示。基础色系由奶油底、卡白和三层墨色组成，覆盖所有界面层级。

二、核心组件一览

导航栏

毛玻璃效果的粘性顶栏，适配移动端与桌面端，Logo 使用 Fraunces 装饰字体。

Hero 区

居中以标题引领，配合标签、副标题与元数据行，构建清晰的信息层级入口。

内容排版

衬线标题 + 无衬线正文的标准搭配，确保中英文长文本的阅读舒适度。

代码块

深色底代码块支持语言标签，行内代码以主色高亮，pre 与 code 均覆盖。

Callout 提示

Info / Warning / Danger 三级提示框，带圆标图标与左侧色条，灵活嵌入正文。

步骤列表

CSS 计数器驱动的编号步骤列表，适合教程与说明文档中的有序指引。

响应式策略

系统以 750px 和 480px 两个断点覆盖平板与手机。 侧排布局退化为单列；卡片网格从三列逐步收拢为单列；字号、间距同步缩减， 确保在所有设备上的可读性。

三、快速上手

在项目中引入 PikeSun 只需复制以下 CSS 变量定义：

:root {
  --pks-primary:  #0071E3;
  --pks-accent:   #FF9500;
  --pks-pop:      #FF3B30;
  --pks-ink:      #1A1A2E;
  --pks-cream:    #fefcf6;
  /* ... see full list in _variables.css */
}

重要提示

i
建议

Fonts 使用 Google Fonts CDN 引入，生产环境建议自托管以获得更快的首屏加载速度。

!
注意

Fraunces 与 Noto Serif SC 均为可变字体，CDN 请求体积较大。如只需特定字重，请在 URL 中限定 wght 轴范围。

!
重要

所有页面必须在 <meta charset="UTF-8"> 之后尽早引入字体 CSS， 避免 FOUT（无样式文本闪烁）。

四、完整集成步骤

  1. 创建 CSS 变量文件

    在项目中新建 _variables.css，复制上述变量定义，确保 :root 块完整。

  2. 引入字体 CDN

    在 <head> 中添加 Google Fonts 链接，优先于自己的样式表加载。

  3. 覆盖全局样式

    将 html、body 的字体与颜色设置为对应的 CSS 变量，完成基础适配。

  4. 按需引入组件

    从模板中提取所需组件（Nav、Hero、Callout、Step-list 等）到独立的 .css 文件。
