# 质量检查清单 — 力太阳设计系统

> 做完设计后逐条对照检查。**P0 必须全过**，任何一条不过就要改。

---

## 🔴 P0 — 必须全过（8 项）

- [ ] **品牌三色出现** — 页面上能同时看到主色 `#0071E3`、强调色 `#FF9500`、点缀色 `#FF3B30`，比例接近 60/30/10
- [ ] **无禁忌元素** — 没有蓝紫渐变、glassmorphism、neon、Inter/Roboto、纯 `#000` 或 `#fff`
- [ ] **无 HTML 默认样式** — 所有 blockquote、列表、表格、引用都来自 components.md，没有浏览器默认渲染
- [ ] **暖色底色** — 背景使用 `#fefcf6` 或 `#faf6eb`，没有冷灰蓝底
- [ ] **衬线+无衬线混搭** — 标题使用 Noto Serif SC，正文使用 Noto Sans SC，不能全是无衬线
- [ ] **响应式正常** — 750px 和 480px 断点下布局正常，内容可读，没有溢出
- [ ] **每 section 布局不同** — 相邻 section 不能使用相同的布局模式（不能连续两个三列网格）
- [ ] **不像 AI 模板** — 截图发社交媒体不会被人说"又是 AI 做的"，有个人风格

---

## 🟡 P1 — 应过（5 项）

- [ ] **至少一个视觉惊喜 section** — 有一个让人"哇"的区域（暗色面板、大数字装饰、视觉冲击）
- [ ] **fluid sizing** — 字号、间距使用 `clamp()` 函数，不是固定 px 值
- [ ] **交互元素有 hover 状态** — 按钮、卡片、链接在悬停时有视觉反馈
- [ ] **移动端是适配不是截肢** — 移动端内容完整，不隐藏重要信息，只重新排列
- [ ] **间距节奏一致** — 视觉上间距有规律，没有"太挤"或"太空"的区域

---

## 🟢 P2 — 加分（4 项）

- [ ] **微妙动效** — 有 subtle 的入场动画或 scroll reveal，但不喧宾夺主
- [ ] **装饰性数字/英文** — 用 Fraunces 做了大号装饰数字或英文标签
- [ ] **尊重 prefers-reduced-motion** — 开启了减少动效的系统设置时，动画会被禁用
- [ ] **图片/元素破容器** — 有元素故意溢出容器边界，打破单调

---

## 自检流程

1. 在浏览器打开页面，缩放到 100%
2. 快速滚动一遍 — 视觉节奏对吗？
3. 缩放到 375px 宽度 — 移动端 OK 吗？
4. 打开 DevTools → 检查所有颜色是否来自品牌色板
5. 检查每一个 `<blockquote>`、`<ul>`、`<ol>`、`<table>` — 有没有忘记加 class 的？
6. 截图 — 发给朋友看，问："这像 AI 做的吗？"
